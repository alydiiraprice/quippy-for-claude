# quippy-for-claude
**Quippy**

A Chrome extension that lets you add comments to your Claude chats — like annotations in a document.
Click the comment icon below any message on claude.ai to leave a note. Replies, colour-coding, and a sidebar view are all included. Comments are stored locally in your browser and persist across sessions.


**Install**

Available on the Chrome Web Store (link once published).


**Privacy**

All data is stored on your device. Nothing is transmitted anywhere. See the privacy policy.
